# 🎬 CinePulse — Movie & TV Show Explorer

**CinePulse** is a modern, responsive web application built with **Vanilla JavaScript**, **CSS3**, and **HTML5**, powered by **The Movie Database (TMDB) API**. It allows users to explore trending movies, search for any film, view detailed info, and manage a personalized watchlist.

🌐 **Live Demo:** [movie-tv-show-explorer.vercel.app](https://movie-tv-show-explorer.vercel.app)

---

## ✨ Features

- 📈 **Trending Movies:** Real-time updates on the most popular movies of the week.
- 🔍 **Instant Search:** Dynamic search engine to find any movie or TV show.
- 🍿 **Detailed Modal View:** Click on any movie card to view overview, release year, rating, and genres.
- 🔴 **Interactive Watchlist:** Add or remove movies from your personal Watchlist (persisted via `localStorage`).
- 📱 **Fully Responsive:** Sleek dark UI optimized for desktop, tablet, and mobile devices.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Modern Flexbox/Grid), Vanilla JavaScript (ES6+)
- **API Integration:** [TMDB API](https://www.themoviedb.org/documentation/api) (Fetch API & Async/Await)
- **Data Persistence:** Browser `localStorage`
- **Hosting:** [Vercel](https://vercel.com/)
